# smart-campus-navigation
Project 2 for CSCE 2110

## Project Description

Menu driven C++ program that loads campus data from four different text files. This program also lets the user find facilities, explore building connections, and find optimal routes.

## Compile and Run

Run from the project root: g++ -std=c++17 -Wall -Wextra src/*.cpp -o campus
